MarkCove のヘルプ

Mac、iPhone、iPad で静かに読める、読み取り専用の Markdown ビューア。

flyoz@vk.com

端末名、OS と MarkCove のバージョン、問題の内容をお知らせください。表示の問題には、機密情報を含まない小さなサンプルが役立ちます。ファイルやスクリーンショットを添付する前に個人情報を取り除いてください。

最初の書類を開く

Finder で .md または .markdown ファイルを選択し、スペースキーを押します。通常の閲覧ウインドウで読むには、「このアプリケーションで開く」→「MarkCove」を選ぶか、アプリで「ファイル」→「開く」を選びます。書類ごとに別のウインドウが開きます。

書類ブラウザから Markdown ファイルを選択してください。iCloud Drive や「ファイル」に対応するプロバイダも利用できます。「ファイル」から Markdown 書類を MarkCove で開くこともできます。MarkCove は選択したファイルを元の場所で読み取ります。

閲覧とナビゲーション

アウトラインでは見出しに移動できます。「検索」では表示中の書類を検索できます。キーボードでは Command-F を使います。「閲覧オプション」では文字サイズ、外観、行幅を調整できます。

MarkCove は元のファイルを編集したり、上書き保存したりしません。書類を変更するには、別のテキストエディタで開いてください。MarkCove が保存するのは、閲覧設定とフォルダのアクセス許可だけです。

ローカル画像とフォルダへのアクセス

書類は、同じフォルダ内の画像や別の Markdown ファイルを参照できます。システムのサンドボックスでこれらのリソースがブロックされる場合は、「設定」→「フォルダへのアクセスを許可」を開き、リソースを含むフォルダを選択してください。許可したアクセスはいつでもすべて取り消せます。

これらのフォルダ内のローカル画像やリンク先のファイルを読み込めなくなる場合があります。ファイルが変更されたり削除されたりすることはありません。

Mac のクイックルック

macOS では、クイックルックのフォルダアクセス権は現在のプレビューセッション中のみ有効で、再度許可が必要になる場合があります。アプリは独自のアクセス権を保存します。プレビュー内の「フォルダを許可」を選んでください。

別の Markdown アプリがプレビューを表示する場合は、「システム設定」でクイックルック機能拡張を確認してください。機能拡張を検出するには、MarkCove がインストールされている必要があります。

画像、リンク、ファイルプロバイダ

リモート画像はデフォルトでブロックされています。有効にすると、画像の配信元に IP アドレスや通常のネットワークリクエストの情報が伝わる場合があります。外部リンクを開くと、MarkCove の外に移動します。「ファイル」のプロバイダが、独自にネットワークを使って書類を取得する場合もあります。

書類が開けないとき

この書類はプレビューの上限である 16 MB を超えています。安全に読むには、テキストエディタで開いてください。

このファイルは読み取り可能な Markdown テキストではありません。UTF-8 または UTF-16 で保存して、もう一度お試しください。

プレビューの読み込みがタイムアウトしました。書類が iCloud またはネットワークドライブにある場合は、ローカルにダウンロードして、もう一度お試しください。
