プライバシーポリシー

アカウント、広告、書類アップロードサービスはありません。

Markdown の表示、コードのハイライト、数式や図の描画はすべてローカルで処理します。MarkCove にはアカウント、広告、アクセス解析、書類のアップロードサービスはありません。

書類は元のまま

MarkCove は元のファイルを編集したり、上書き保存したりしません。書類を変更するには、別のテキストエディタで開いてください。MarkCove が保存するのは、閲覧設定とフォルダのアクセス許可だけです。

お使いの端末で

MarkCove は閲覧設定とフォルダへのアクセス許可を端末に保存します。Mac では閲覧設定をクイックルック拡張機能と共有します。OS はシステム設定に従い、最近使った書類、ウインドウの状態、診断情報を保持する場合があります。設定でフォルダの許可を消去すると、クイックルックが次のプレビューを準備するときに反映されます。表示済みの内容はプレビューを閉じるまでメモリに残り、開いている書類へのアクセスも閉じるまで続く場合があります。

macOS では、クイックルックのフォルダアクセス権は現在のプレビューセッション中のみ有効で、再度許可が必要になる場合があります。アプリは独自のアクセス権を保存します。プレビュー内の「フォルダを許可」を選んでください。

これらのフォルダ内のローカル画像やリンク先のファイルを読み込めなくなる場合があります。ファイルが変更されたり削除されたりすることはありません。

画像、リンク、ファイルプロバイダ

リモート画像はデフォルトでブロックされています。有効にすると、画像の配信元に IP アドレスや通常のネットワークリクエストの情報が伝わる場合があります。外部リンクを開くと、MarkCove の外に移動します。「ファイル」のプロバイダが、独自にネットワークを使って書類を取得する場合もあります。

Web サイトやメールのリンクは、通常使用するアプリで開きます。リンク先の Markdown 書類は、ファイルにアクセスできる場合に MarkCove で開きます。サンプルには専用のフォルダがないため、ローカルファイルへのリンクは利用できません。

このサイトとサポートメール

このサイトは GitHub Pages でホストされています。GitHub はサイトの提供と保護のため、IP アドレスなどの通常のアクセス情報を処理する場合があります。このサイトにアクセス解析、広告、追跡 Cookie は追加していません。サポートにメールを送ると、返信のためにメールアドレス、本文、添付ファイルを受け取ります。機密書類は送らないでください。MarkCove には削除対象となるリモートアカウントや書類データベースはありません。
