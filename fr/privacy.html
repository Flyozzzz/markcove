Politique de confidentialité

Sans compte, publicité ni service d’envoi de documents.

Le rendu Markdown, la coloration du code, les formules et les diagrammes sont traités localement. MarkCove n’a ni compte, ni publicité, ni analyse d’utilisation, ni service d’envoi de documents.

Vos documents restent intacts

MarkCove ne modifie ni n’écrase jamais votre fichier original. Pour modifier un document, ouvrez-le dans un éditeur de texte distinct. MarkCove enregistre uniquement vos préférences de lecture et vos autorisations d’accès aux dossiers.

Sur votre appareil

MarkCove conserve les préférences de lecture et les autorisations de dossiers sur votre appareil. Sur Mac, les préférences sont partagées avec Coup d’œil. Le système peut conserver les documents récents, l’état des fenêtres et des diagnostics selon vos réglages. Après la suppression des autorisations dans les réglages, Coup d’œil applique le changement au prochain aperçu. Le contenu déjà affiché peut rester en mémoire jusqu’à la fermeture de l’aperçu, et l’accès à un document peut durer tant qu’il reste ouvert.

Sur macOS, l’accès de Coup d’œil au dossier vaut pour la session d’aperçu et peut être redemandé. L’app conserve ses propres autorisations. Choisissez Autoriser un dossier dans l’aperçu.

Les images locales et les fichiers liés présents dans ces dossiers pourraient ne plus se charger. Vos fichiers ne seront ni modifiés ni supprimés.

Images, liens et services de fichiers

Les images distantes sont bloquées par défaut. Si vous les activez, l’hébergeur de l’image peut recevoir votre adresse IP et les informations habituelles d’une requête réseau. L’ouverture d’un lien externe vous fait également quitter MarkCove. Votre fournisseur de fichiers dans Fichiers peut utiliser le réseau indépendamment pour récupérer un document.

Les liens vers les sites web et les adresses e-mail s’ouvrent dans vos apps habituelles. Les documents Markdown liés s’ouvrent dans MarkCove lorsque le fichier est accessible. L’exemple n’a pas de dossier propre : les liens vers des fichiers locaux n’y sont donc pas disponibles.

Ce site et les e-mails d’assistance

Ce site est hébergé par GitHub Pages. GitHub peut traiter des informations d’accès courantes, dont votre adresse IP, pour fournir et protéger le site. Nous n’ajoutons ni analyse d’audience, ni publicité, ni cookies de suivi. Si vous écrivez à l’assistance, nous recevons votre adresse e-mail, votre message et vos pièces jointes pour vous répondre. N’envoyez pas de documents sensibles. MarkCove n’a ni compte distant ni base de documents à supprimer.
