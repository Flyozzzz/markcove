Ouvrir votre premier document

Dans le Finder, sélectionnez un fichier .md ou .markdown et appuyez sur la barre d’espace. Pour une fenêtre de lecture complète, choisissez Ouvrir avec → MarkCove, ou utilisez Fichier → Ouvrir dans l’app. Chaque document s’ouvre dans sa propre fenêtre.

Choisissez un fichier Markdown dans le navigateur de documents, y compris dans iCloud Drive et les services compatibles avec Fichiers. Vous pouvez aussi ouvrir des documents Markdown dans MarkCove depuis Fichiers. MarkCove lit le fichier sélectionné à son emplacement d’origine.

Lecture et navigation

Le plan permet d’accéder aux titres. Rechercher permet de trouver du texte dans le document affiché ; utilisez Commande-F avec un clavier. Options de lecture permet de régler la taille du texte, l’apparence et la largeur des lignes.

MarkCove ne modifie ni n’écrase jamais votre fichier original. Pour modifier un document, ouvrez-le dans un éditeur de texte distinct. MarkCove enregistre uniquement vos préférences de lecture et vos autorisations d’accès aux dossiers.

Images locales et accès aux dossiers

Les documents peuvent faire référence à des images ou à d’autres fichiers Markdown voisins. Si l’environnement isolé du système bloque ces ressources, ouvrez Réglages → Autoriser un dossier et sélectionnez le dossier qui les contient. Vous pouvez révoquer tous les accès accordés à tout moment.

Les images locales et les fichiers liés présents dans ces dossiers pourraient ne plus se charger. Vos fichiers ne seront ni modifiés ni supprimés.

Coup d’œil sur Mac

Sur macOS, l’accès de Coup d’œil au dossier vaut pour la session d’aperçu et peut être redemandé. L’app conserve ses propres autorisations. Choisissez Autoriser un dossier dans l’aperçu.

Si une autre app Markdown prend en charge l’aperçu, vérifiez vos extensions Coup d’œil dans Réglages Système. MarkCove doit être installé pour que son extension puisse être détectée.

Images, liens et services de fichiers

Les images distantes sont bloquées par défaut. Si vous les activez, l’hébergeur de l’image peut recevoir votre adresse IP et les informations habituelles d’une requête réseau. L’ouverture d’un lien externe vous fait également quitter MarkCove. Votre fournisseur de fichiers dans Fichiers peut utiliser le réseau indépendamment pour récupérer un document.

Si un document ne s’ouvre pas

Ce document dépasse la limite de 16 Mo pour l’aperçu. Ouvrez-le dans un éditeur de texte pour le lire en toute sécurité.

Ce fichier ne contient pas de texte Markdown lisible. Enregistrez-le en UTF-8 ou UTF-16 et réessayez.

Cet aperçu a mis trop de temps à se charger. Si le document est stocké dans iCloud ou sur un lecteur réseau, téléchargez-le sur votre appareil et réessayez.
