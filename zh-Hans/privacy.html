隐私政策

无需账户，无广告，不提供文档上传服务。

Markdown 渲染、代码高亮、数学公式和图表均在本地处理。MarkCove 无账户、无广告、无分析追踪，也不提供文档上传服务。

你的文档，保持原样

MarkCove 绝不会编辑或覆盖保存您的原始文件。如需修改文档，请在其他文本编辑器中打开。MarkCove 只会保存阅读偏好设置和文件夹访问权限。

在你的设备上

MarkCove 在设备上保存阅读偏好和文件夹访问权限。在 Mac 上，阅读偏好与快速查看扩展共享。操作系统可能根据系统设置保留最近文档记录、窗口状态和诊断信息。在设置中清除文件夹权限后，快速查看会在下次准备预览时应用重置。已显示的内容可能保留在内存中，直到关闭预览；对已打开文档的访问权限也可能持续到文档关闭。

在 macOS 上，快速查看的文件夹访问权限仅在当前预览会话中有效，之后可能需要重新授权。应用会保存自己的文件夹权限。请在预览中选择“允许访问文件夹”。

这些文件夹中的本地图像和链接的文件可能无法继续加载。您的文件不会被更改或删除。

图像、链接与文件提供商

默认阻止远程图像。如果启用，图像托管方可能会收到您的 IP 地址和常规网络请求信息。打开外部链接也会离开 MarkCove。“文件”中的文件提供商可能会自行使用网络获取文档。

网站和电子邮件链接会在您常用的应用中打开。链接的 Markdown 文档在可访问时会在 MarkCove 中打开。示例没有自己的文件夹，因此其中的本地文件链接不可用。

本网站与支持邮件

本网站由 GitHub Pages 托管。GitHub 可能处理包括 IP 地址在内的常规访问信息，以提供网站服务并保障安全。本网站未添加分析工具、广告或跟踪 Cookie。如果你发送支持邮件，我们会收到你的邮箱地址、消息和附件，以便回复。请勿发送敏感文档。MarkCove 没有需要删除的远程用户账户或文档数据库。
