MarkCove 使用帮助

适用于 Mac、iPhone 和 iPad 的安静、只读 Markdown 阅读器。

flyoz@vk.com

请说明设备、系统版本、MarkCove 版本以及遇到的问题。对于显示问题，一份不含敏感信息的小示例会很有帮助。附加文件或截图前，请移除私人信息。

打开第一份文档

在 Finder 中选择 .md 或 .markdown 文件，然后按空格键。如需完整的阅读窗口，请选择“打开方式”→“MarkCove”，或在应用中使用“文件”→“打开”。每个文档都会在独立窗口中打开。

从文档浏览器中选择 Markdown 文件，支持 iCloud Drive 和“文件”中的其他文件提供商。您也可以从“文件”中使用 MarkCove 打开 Markdown 文档。MarkCove 会直接读取原位置的文件。

阅读与导航

大纲可跳转到各级标题。“查找”会搜索渲染后的文档；使用键盘时可按 Command-F。“阅读选项”可调整文字大小、外观和行宽。

MarkCove 绝不会编辑或覆盖保存您的原始文件。如需修改文档，请在其他文本编辑器中打开。MarkCove 只会保存阅读偏好设置和文件夹访问权限。

本地图像与文件夹访问权限

文档可以引用同一文件夹中的图像或其他 Markdown 文件。如果系统沙盒阻止访问这些资源，请打开“设置”→“允许访问文件夹”，然后选择资源所在的文件夹。您随时可以移除所有已授予的访问权限。

这些文件夹中的本地图像和链接的文件可能无法继续加载。您的文件不会被更改或删除。

Mac 上的快速查看

在 macOS 上，快速查看的文件夹访问权限仅在当前预览会话中有效，之后可能需要重新授权。应用会保存自己的文件夹权限。请在预览中选择“允许访问文件夹”。

如果预览由其他 Markdown 应用提供，请在“系统设置”中检查快速查看扩展。必须先安装 MarkCove，系统才能发现其扩展。

图像、链接与文件提供商

默认阻止远程图像。如果启用，图像托管方可能会收到您的 IP 地址和常规网络请求信息。打开外部链接也会离开 MarkCove。“文件”中的文件提供商可能会自行使用网络获取文档。

文档无法打开时

此文档超出 16 MB 的预览大小限制。请在文本编辑器中打开，以便安全阅读。

此文件不是可读取的 Markdown 文本。请将其存储为 UTF-8 或 UTF-16 后重试。

此预览加载超时。如果文档存储在 iCloud 或网络驱动器上，请先下载到本地后重试。
