Política de privacidad

Sin cuenta, anuncios ni servicio de subida de documentos.

La representación de Markdown, el resaltado de código, las fórmulas y los diagramas se procesan localmente. MarkCove no tiene cuentas, publicidad, análisis de uso ni servicio de subida de documentos.

Tus documentos, sin cambios

MarkCove nunca edita ni sobrescribe el archivo original. Para modificar un documento, ábrelo en un editor de texto aparte. MarkCove solo guarda las preferencias de lectura y los permisos de acceso a carpetas.

En tu dispositivo

MarkCove guarda las preferencias de lectura y los permisos de carpetas en tu dispositivo. En Mac comparte las preferencias con Vista Rápida. El sistema puede conservar documentos recientes, el estado de las ventanas y diagnósticos según tus ajustes. Al borrar los permisos en Ajustes, Vista Rápida aplica el cambio al preparar la siguiente vista previa. El contenido ya mostrado puede permanecer en memoria hasta cerrar la vista previa, y el acceso a un documento abierto puede durar mientras siga abierto.

En macOS, Quick Look accede a la carpeta durante la sesión de vista previa y puede volver a pedir permiso. La app recuerda sus propios permisos. Usa Permitir una carpeta dentro de la vista previa.

Las imágenes locales y los archivos enlazados de esas carpetas podrían dejar de cargarse. Tus archivos no se modificarán ni se eliminarán.

Imágenes, enlaces y proveedores de archivos

Las imágenes remotas están bloqueadas por omisión. Si las activas, el servidor de imágenes puede recibir tu dirección IP y la información habitual de las solicitudes de red. Al abrir un enlace externo también sales de MarkCove. Tu proveedor de Archivos puede usar la red de forma independiente para obtener un documento.

Los enlaces a sitios web y correos electrónicos se abren en tus apps habituales. Los documentos Markdown enlazados se abren en MarkCove si el archivo es accesible. El ejemplo no tiene una carpeta propia, por lo que sus enlaces a archivos locales no están disponibles.

Este sitio web y el correo de soporte

Este sitio está alojado en GitHub Pages. GitHub puede procesar información de acceso habitual, incluida tu dirección IP, para servir y proteger el sitio. No añadimos analítica, publicidad ni cookies de seguimiento. Si escribes a soporte, recibimos tu dirección de correo, mensaje y archivos adjuntos para responder. No envíes documentos confidenciales. MarkCove no tiene cuentas remotas ni una base de datos de documentos que eliminar.
