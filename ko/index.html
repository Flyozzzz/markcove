macOS

Mac의 훑어보기

Finder에서 .md 또는 .markdown 파일을 선택하고 스페이스 바를 누르세요. 전체 읽기 윈도우로 보려면 다음으로 열기 → MarkCove를 선택하거나 앱에서 파일 → 열기를 사용하세요. 각 문서는 별도의 윈도우에서 열립니다.

iOS · iPadOS

첫 문서 열기

문서 탐색기에서 Markdown 파일을 선택하세요. iCloud Drive와 파일 앱이 지원하는 제공업체도 이용할 수 있습니다. 파일 앱에서 Markdown 문서를 MarkCove로 열 수도 있습니다. MarkCove는 선택한 파일을 원래 위치에서 읽습니다.

macOS에서 훑어보기의 폴더 접근은 현재 미리보기 세션 동안 유효하며 다시 허용해야 할 수 있습니다. 앱은 자체 접근 권한을 저장합니다. 미리보기 안의 폴더 허용을 사용하세요.

개인정보 보호

문서는 원래 그대로

MarkCove는 원본 파일을 편집하거나 덮어쓰지 않습니다. 문서를 수정하려면 별도의 텍스트 편집기에서 여세요. MarkCove는 읽기 설정과 폴더 접근 권한만 저장합니다.

Markdown 표시, 코드 강조, 수식 및 다이어그램 처리는 모두 기기 내에서 이루어집니다. MarkCove에는 계정, 광고, 분석 또는 문서 업로드 서비스가 없습니다.

원격 이미지는 기본적으로 차단됩니다. 활성화하면 이미지 호스팅 서버에 사용자의 IP 주소와 일반적인 네트워크 요청 정보가 전달될 수 있습니다. 외부 링크를 열면 MarkCove 밖으로 이동합니다. 파일 앱의 제공업체가 문서를 가져오기 위해 자체적으로 네트워크를 사용할 수도 있습니다.
