개인정보 처리방침

계정, 광고, 문서 업로드 서비스가 없습니다.

Markdown 표시, 코드 강조, 수식 및 다이어그램 처리는 모두 기기 내에서 이루어집니다. MarkCove에는 계정, 광고, 분석 또는 문서 업로드 서비스가 없습니다.

문서는 원래 그대로

MarkCove는 원본 파일을 편집하거나 덮어쓰지 않습니다. 문서를 수정하려면 별도의 텍스트 편집기에서 여세요. MarkCove는 읽기 설정과 폴더 접근 권한만 저장합니다.

사용자의 기기에서

MarkCove는 읽기 설정과 폴더 접근 권한을 기기에 저장합니다. Mac에서는 읽기 설정을 훑어보기 확장 프로그램과 공유합니다. 운영체제는 시스템 설정에 따라 최근 문서 기록, 윈도우 상태, 진단 정보를 보관할 수 있습니다. 설정에서 폴더 권한을 지우면 훑어보기가 다음 미리보기를 준비할 때 적용됩니다. 이미 표시된 내용은 미리보기를 닫을 때까지 메모리에 남을 수 있으며, 열린 문서의 접근 권한도 문서를 닫을 때까지 유지될 수 있습니다.

macOS에서 훑어보기의 폴더 접근은 현재 미리보기 세션 동안 유효하며 다시 허용해야 할 수 있습니다. 앱은 자체 접근 권한을 저장합니다. 미리보기 안의 폴더 허용을 사용하세요.

해당 폴더의 로컬 이미지와 링크된 파일을 더 이상 불러오지 못할 수 있습니다. 파일이 변경되거나 삭제되지는 않습니다.

이미지, 링크, 파일 제공업체

원격 이미지는 기본적으로 차단됩니다. 활성화하면 이미지 호스팅 서버에 사용자의 IP 주소와 일반적인 네트워크 요청 정보가 전달될 수 있습니다. 외부 링크를 열면 MarkCove 밖으로 이동합니다. 파일 앱의 제공업체가 문서를 가져오기 위해 자체적으로 네트워크를 사용할 수도 있습니다.

웹사이트와 이메일 링크는 평소 사용하는 앱에서 열립니다. 링크된 Markdown 문서는 파일에 접근할 수 있을 때 MarkCove에서 열립니다. 예제에는 자체 폴더가 없으므로 로컬 파일 링크를 사용할 수 없습니다.

이 웹사이트와 지원 이메일

이 사이트는 GitHub Pages에서 호스팅됩니다. GitHub는 사이트 제공과 보안을 위해 IP 주소를 포함한 일반적인 접속 정보를 처리할 수 있습니다. 이 사이트에는 분석 도구, 광고 또는 추적 쿠키를 추가하지 않았습니다. 지원 이메일을 보내면 답변을 위해 이메일 주소, 메시지 및 첨부 파일을 받습니다. 민감한 문서는 보내지 마세요. MarkCove에는 삭제할 원격 계정이나 문서 데이터베이스가 없습니다.
