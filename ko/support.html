MarkCove 도움말

Mac, iPhone, iPad를 위한 차분한 읽기 전용 Markdown 뷰어.

기기, 시스템 버전, MarkCove 버전과 발생한 문제를 알려주세요. 표시 문제에는 민감한 정보가 없는 작은 예시가 도움이 됩니다. 파일이나 스크린샷을 첨부하기 전에 개인정보를 지워주세요.

첫 문서 열기

Finder에서 .md 또는 .markdown 파일을 선택하고 스페이스 바를 누르세요. 전체 읽기 윈도우로 보려면 다음으로 열기 → MarkCove를 선택하거나 앱에서 파일 → 열기를 사용하세요. 각 문서는 별도의 윈도우에서 열립니다.

문서 탐색기에서 Markdown 파일을 선택하세요. iCloud Drive와 파일 앱이 지원하는 제공업체도 이용할 수 있습니다. 파일 앱에서 Markdown 문서를 MarkCove로 열 수도 있습니다. MarkCove는 선택한 파일을 원래 위치에서 읽습니다.

읽기와 탐색

개요에서 제목으로 이동할 수 있습니다. 찾기는 표시된 문서를 검색합니다. 키보드에서는 Command-F를 사용하세요. 읽기 옵션에서는 텍스트 크기, 화면 모드 및 줄 너비를 조절할 수 있습니다.

MarkCove는 원본 파일을 편집하거나 덮어쓰지 않습니다. 문서를 수정하려면 별도의 텍스트 편집기에서 여세요. MarkCove는 읽기 설정과 폴더 접근 권한만 저장합니다.

로컬 이미지와 폴더 접근 권한

문서는 같은 폴더의 이미지나 다른 Markdown 파일을 참조할 수 있습니다. 시스템 샌드박스가 이러한 리소스를 차단하면 설정 → 폴더 접근 허용을 열고 해당 폴더를 선택하세요. 허용한 접근 권한은 언제든지 모두 해제할 수 있습니다.

해당 폴더의 로컬 이미지와 링크된 파일을 더 이상 불러오지 못할 수 있습니다. 파일이 변경되거나 삭제되지는 않습니다.

Mac의 훑어보기

macOS에서 훑어보기의 폴더 접근은 현재 미리보기 세션 동안 유효하며 다시 허용해야 할 수 있습니다. 앱은 자체 접근 권한을 저장합니다. 미리보기 안의 폴더 허용을 사용하세요.

다른 Markdown 앱이 미리보기를 표시한다면 시스템 설정에서 훑어보기 확장 프로그램을 확인하세요. 확장 프로그램을 찾으려면 MarkCove가 설치되어 있어야 합니다.

이미지, 링크, 파일 제공업체

원격 이미지는 기본적으로 차단됩니다. 활성화하면 이미지 호스팅 서버에 사용자의 IP 주소와 일반적인 네트워크 요청 정보가 전달될 수 있습니다. 외부 링크를 열면 MarkCove 밖으로 이동합니다. 파일 앱의 제공업체가 문서를 가져오기 위해 자체적으로 네트워크를 사용할 수도 있습니다.

문서가 열리지 않을 때

이 문서는 미리보기 한도인 16 MB를 초과합니다. 안전하게 읽으려면 텍스트 편집기에서 여세요.

이 파일은 읽을 수 있는 Markdown 텍스트가 아닙니다. UTF-8 또는 UTF-16으로 저장한 뒤 다시 시도하세요.

미리보기 불러오기가 시간 초과되었습니다. 문서가 iCloud나 네트워크 드라이브에 있다면 기기에 다운로드한 뒤 다시 시도하세요.
