Help with MarkCove

A quiet, read-only Markdown viewer for Mac, iPhone and iPad.

Open your first document

In Finder, select a .md or .markdown file and press Space. For a full reading window, choose Open With → MarkCove, or use File → Open in the app. Each document opens in its own window.

Choose a Markdown file from the document browser, including iCloud Drive and supported Files providers. You can also open Markdown documents in MarkCove from Files. MarkCove reads the selected file in place.

Reading and navigation

The outline jumps to headings. Find searches the rendered document; use Command-F with a keyboard. Reading Options adjusts text size, appearance and line width.

MarkCove never edits or saves over your original file. To change a document, open it in a separate text editor. Reading preferences and folder permissions are the only information MarkCove saves.

Local images and folder access

Documents can refer to images or other Markdown files beside them. If these resources are blocked by the system sandbox, open Settings → Allow a Folder and select the containing folder. You can remove all granted access at any time.

Local images and linked files in those folders may stop loading. Your files will not be changed or deleted.

Quick Look on Mac

On macOS, Quick Look folder access lasts for the current preview session and may need to be granted again. The app remembers its own folder permissions. Use Allow a Folder inside the preview.

If another Markdown app owns the preview, check your Quick Look extensions in System Settings. MarkCove must be installed before its extension can be discovered.

Images, links and file providers

Remote images are blocked by default. If you enable them, the image host can receive your IP address and ordinary network request information. Opening an external link also leaves MarkCove. Your Files provider may independently use the network to retrieve a document.

If a document will not open

This document exceeds the 16 MB preview limit. Open it in a text editor to read it safely.

This file is not readable Markdown text. Save it as UTF-8 or UTF-16 and try again.

This preview took too long to load. If the document is stored in iCloud or on a network drive, download it locally and try again.
